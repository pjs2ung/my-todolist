## 참조 이미지 분석

다크 네이비 배경 + 그라데이션 블루 포인트 컬러 + 화이트 텍스트 조합의 히어로 섹션. 카드형 그리드(아이콘+제목+설명), 필드형(Filled) 버튼과 아웃라인 버튼 2종 조합이 특징.

## 1. 컬러 팔레트

| 용도            | 색상                                     | 값        |
| --------------- | ----------------------------------------- | --------- |
| Background(진함) | 네이비 (그라데이션 시작)                  | `#0B1D4D` |
| Background(연함) | 네이비-블루 (그라데이션 끝)               | `#1B3A8A` |
| Primary(강조)    | 브라이트 블루 (제목 그라데이션, 버튼)     | `#2F8CFF` |
| Primary Hover    | 브라이트 블루 진하게                      | `#1E6FD9` |
| Text(제목)       | 화이트                                    | `#FFFFFF` |
| Text(본문)       | 라이트 그레이(화이트 80%)                 | `#D6DEEF` |
| Card Background  | 화이트 8% 오버레이(반투명, 네이비 위)     | `rgba(255,255,255,0.08)` |
| Border/Divider   | 화이트 15% 오버레이                       | `rgba(255,255,255,0.15)` |

Primary 컬러는 이 프로젝트(TodoList)의 CTA 버튼·활성 상태·상태뱃지(진행중 등)에 사용한다.

## 2. 타이포그래피

| 요소       | 크기(desktop) | 굵기 | 색상               |
| ---------- | -------------- | ---- | ------------------- |
| H1(히어로) | 48px           | 800(ExtraBold) | 화이트 / 강조부만 Primary 그라데이션 |
| Body(부제) | 16px           | 400  | Text(본문) |
| Card Title | 18px           | 700(Bold) | 화이트 |
| Card Desc  | 14px           | 400  | Text(본문) |
| Button     | 15px           | 600(SemiBold) | 버튼별 상이(아래 참조) |

폰트 패밀리는 시스템 폰트 스택 사용(별도 웹폰트 로드 없음 — 성능/YAGNI): `-apple-system, "Segoe UI", "Malgun Gothic", sans-serif`.

## 3. 버튼

- **Filled(Primary)**: 배경 `#2F8CFF`, 텍스트 화이트, hover 시 `#1E6FD9`. 주요 액션(로그인, 할일 등록 등)에 사용.
- **Outline**: 배경 투명, 테두리 화이트 1px, 텍스트 화이트, hover 시 배경 화이트 10% 오버레이. 보조 액션(취소, 더보기 등)에 사용.
- 공통: `border-radius: 6px`, `padding: 10px 20px`.

## 4. 카드

- 배경: Card Background(반투명), `border: 1px solid` Border/Divider, `border-radius: 12px`.
- 내부: 아이콘(원형 배경) + 타이틀 + 설명 텍스트 세로 배치, `padding: 20px`.
- 그리드: 데스크톱 기준 카드 간 `gap: 16px`, 반응형 시 1열로 스택.

## 5. 상태 뱃지 매핑 (도메인 정의서 §5 연계)

기존 [4-wireframe.md](./4-wireframe.md)의 상태뱃지 규칙에 이 팔레트를 적용한다.

| 상태       | 배경색                | 텍스트색  |
| ---------- | ---------------------- | --------- |
| 시작전     | `rgba(255,255,255,0.12)` | `#D6DEEF` |
| 진행중     | `#2F8CFF`               | `#FFFFFF` |
| 완료       | `#2FBF71`(그린, 팔레트 외 보조색) | `#FFFFFF` |
| 지연       | `#E5484D`(레드, 팔레트 외 보조색) | `#FFFFFF` |

완료/지연은 참조 이미지에 없는 상태라 상태 구분이 명확한 보조 색상(그린/레드)을 최소 추가했다.

## 6. 적용 범위 메모

TodoList는 라이트 배경 기반 생산성 툴(와이어프레임 기준)이라, 참조 이미지의 다크 네이비 배경을 전체 배경으로 그대로 쓰기보다 **Primary 컬러·버튼/카드 스타일·타이포그래피 위계**만 채용하고 배경은 화이트/라이트 그레이 유지를 권장. 다크 모드를 별도로 요구하면 Background 팔레트를 그대로 다크 테마 토큰으로 사용 가능.
